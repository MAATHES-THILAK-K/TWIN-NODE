# ⚙️ TWIN-NODE – Motor Controller
## Overview

The **TWIN-NODE Motor Controller** is a compact wireless motor control module designed to work with the TWIN-NODE water level monitoring system.
It enables **remote ON/OFF control of a water pump** using **ESP-NOW**, without internet connectivity.

---
![Motor Controller PCB](https://github.com/MAATHES-THILAK-K/TWIN-NODE/blob/main/MOTOR%20CONTROLLER/IMAGES/FRONT.png)
---

## Key Features

* ESP-01 (ESP8266) based controller
* Wireless control using ESP-NOW
* Relay-based motor switching
* Electrical isolation between control and load
* Manufacturable PCB design

---
